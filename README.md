# Monsters Website
## A normal website in the Monster's World...

## Description:
### Its a spooky webpage showcasing random monster and their details, made navbar, hero pages, 404 error page and added favicon icon to the page.

## How to use?
### You can click on get started to view the monsters page or you can scroll down, Also to view the 404 error page you have to click on the about button in the navbar.
